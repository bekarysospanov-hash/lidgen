## Правило, которое нельзя нарушить

**`DESIGN.md` в корне — единственный источник правды по визуалу. Читать его
первым, до единой строки кода.** Не «если вспомнишь» — первым действием.

Причина: генерация дизайна деградирует от итерации к итерации, потому что
у неё нет обязательного входа. Каждый прогон заново выбирает палитру и шрифты.
Сегодня это проверено дважды — оба раза модель уходила в свою сторону,
пока не появился файл.

Порядок правок всегда один: **`DESIGN.md` → `npm run design:tokens` → код.**
Поменять цвет в компоненте, не тронув файл, — значит развести их.

## Пайплайн — пять команд

| Команда | Что делает |
|---|---|
| `npm run design:lint` | схема файла, ссылки токенов, контраст WCAG |
| `npm run design:tokens` | `DESIGN.md` → `src/design-tokens.css` (Tailwind `@theme`) |
| `npm run design:check` | ловит цвета, шрифты и **запрещённые утилиты** мимо файла |
| `npx design.md diff before.md DESIGN.md` | что именно изменилось в системе |
| `npm run design:spec` | обновить локальную копию спеки формата |

**`design:check` ловит два класса:** литералы (`#ff0000`, `oklch(`, `font-family` строкой)
и запрещённые утилиты Tailwind (`rounded-*`, `font-bold`, `shadow-*`, `italic`,
лайм заливкой). Второе нужно потому, что Tailwind v4 свои дефолты нашими
токенами не заменяет, а дополняет.

Исключение помечается в коде: `design-ok: <причина>` на строке или над ней.
**Причина обязательна.** Больше двух-трёх исключений — сигнал, что неправ файл.

**Чего проверки не удержат:** «не набирать капсом связный текст», «выравнивание
левое», «не показывать заказчику названия материалов». Это проза, держится
только чтением файла.

## С чего вайбкодить

Порядок в `docs/story-map.md`. Срез 1 «Скелет» — 10 историй, из них
**US-04, US-05a, US-05b уже сделаны**. Осталось по срезу 1:

1. **US-02 каталог мастерских** — берите первым. Это единственная содержательная
   дыра в макетах Stitch, и это второй экран, на котором станет видно,
   держит ли система. После него прогнать `design:check` и `hallmark audit`
2. **US-12** подтверждение телефона · **US-16** страница ожидания
3. **US-17, US-18, US-19a** кабинет мебельщика и форма КП
4. **US-21** страница предложений по токену

**Контракт API** — до моков, не после. `src/contract` с zod-схемами, документ
рядом. Моки пишутся **по контракту**, иначе стык с бэкендом потеряет неделю.

## Чего эксперимент не ответит

Дойдёт ли заявка до сделки — цикл мебели 3–8 недель, тест до неё не доживёт.
На 15 заявках это проверка существования сигнала, а не статистика рынка.

**И главное, что не решается кодом:** без 3+ мебельщиков на приёме запуска нет,
сколько бы экранов вы ни написали. A1 — единственный критический путь,
и он на маркетологе.
