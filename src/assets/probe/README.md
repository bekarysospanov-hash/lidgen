PROBE: временные фотографии для проверки вёрстки.

Это случайные снимки из галереи PM, а НЕ портфолио мебельщиков.
В эксперимент они не идут: спека §4 и PRD §7 запрещают показывать
сгенерированные карточки, чужие портфолио и вымышленные мастерские.
Заменяются реальными работами реальных мастерских (трек A1, маркетолог)
до GATE 1. Удаляются вместе с оболочкой: grep -rn "PROBE:" .
